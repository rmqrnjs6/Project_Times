# Project Times 개발 기반

기준일: 2026-11-06, Asia/Seoul. 공유 대화 보존본의 마지막 개발 단계부터 이어가기 위한 재구현이다. 이전 클라우드 파일·첨부 PDF·계산기 전체 소스가 복구된 것은 아니다.

## 요청과 처리 흐름

브라우저 → Tomcat의 Java Servlet → 업무 처리 → Python 산술 서비스 또는 PostgreSQL → JSON 응답 / JSP 화면.

- `web/src/main/webapp/index.jsp`: 화면 골격. 스크립트·스타일은 별도 파일로 분리한다.
- `Controller`: 요청 경로, JSON 형식·크기·질문 검사, HTTP 응답. Python 호출 및 DB 저장을 연결한다.
- `AnalysisService`: 내부 Python 서비스에 연결 제한 3초, 요청 제한 5초로 통신한다. 숨은 자동 재시도를 하지 않는다.
- `Database`: JDBC 준비 상태, 질문 저장·최근 50개 조회, 계산 입력·결과·정책 버전 저장. SQL은 매개변수 바인딩을 사용한다.
- `Application`: Flyway 마이그레이션 후 서비스를 등록한다. 마이그레이션 실패 시 정상 기동으로 취급하지 않는다.
- `app/scoring.py`: Decimal 28자리·내부 HALF_EVEN, 표시 HALF_UP. 원문 진위 판별 기능은 없다.
- `V1__baseline.sql`: 연결 점검 질문, 계산 실행 이력의 최초 스키마.

공유 기록의 기술 합의인 JSP·Java·Python·PostgreSQL·Docker를 유지한다. 원본 구현이 없으므로 Java 웹 계층은 Java 21·Jakarta Servlet 6·Tomcat 10.1의 WAR로 재구현했다. 과거 응답에 등장한 Spring Boot 구현과 동일한 소스라고 주장하지 않는다.

## 산술 정책 reference-v1

F/S/I/T/C/R/E의 순서와 가중치 0.25/0.20/0.10/0.10/0.10/0.10/0.15는 보존본 message-40의 `PAPER_WEIGHTS` 예시에서 가져온 참조 설정이다. 논문 원본과 실제 판별 데이터로 검증된 현행 평가 기준은 아니다. 화면용 가중치 값은 원문 전체가 없어 만들지 않았다.

현재 각 축은 사용자가 공급한 긍정·부정·미확인 수량을 받아 산술 범위로 바꾼다. 각 축의 실제 전문 판별 규칙을 구현한 것이 아니다. 총수 10, 긍정 6, 부정 2, 미확인 2라면 60~80%로 계산한다. 미확인은 분모에 남긴다. 범위는 신뢰구간이나 정답 확률이 아니다.

검토 전에는 E만 제외하고 나머지 가중치를 재정규화한다. 검토 후에는 E가 필요하다. 그 외 필수 축이 비면 종합값은 null이다. R은 종합 계산에서 `[1-upper, 1-lower]`로 한 번 역변환한다. API의 축별 `raw`는 역변환 전 위험 값임을 구분한다. 표·레이더 차트는 아직 구현하지 않았다.

`paired_change`는 산술 변화량만 계산한다. 동일 질문·모델·기준 버전의 실제 짝 확인은 호출 계층에서 구현해야 하므로 현재 웹 API에는 노출하지 않았다.

## 저장과 실패

계산 요청·결과·정책 버전은 하나의 INSERT로 함께 저장한다. 저장이 성공한 후에만 실행 ID를 반환한다. 기존 계산 행을 수정하는 API는 없다. 네트워크 단절 후 재요청에 대한 중복 방지·멱등성은 미구현이다.

DB 또는 Python이 응답하지 않으면 `/ready`는 503을 반환한다. Compose의 재시작 정책은 프로세스 종료에 대한 정책이다. unhealthy 판정만으로 컨테이너가 자동 재시작되는 것은 아니다. 재시작 정책은 백업이나 작업 재개를 대신하지 않는다.

## 다음 개발 단계

1. 로그인·서버 권한 검사·CSRF·감사 이력. 현재는 인증 없는 로컬 개발 전용이다.
2. 검증 작업·AI 원본 응답·주장·근거·독립 전문가 검토의 스키마와 상태 전이.
3. Java가 단일 주체로 관리하는 호출·시간·비용 예산. 대화의 최초 포함 10회는 전체 작업/단계 범위를 확정해야 하며 아직 활성화되지 않았다.
4. 단계별 체크포인트·실패 사유·부분 완료·재개. 재처리에도 누적 비용·시도 횟수는 유지한다.
5. 실제 AI·검색 연동, 원문 판별, 반례 데이터 검증, 동일 조건의 전후 비교 및 차트.

개인 메모리 내보내기의 민감정보는 코드·시드·문서에 복사하지 않았다. 기존 공개 대화 보존본은 별도 자료로 유지한다.
