# Project Times · AI 5종 구성 및 API 비용 정리

작성일: 2026년 11월 11일 (한국시간)
기록 범위: 이번 대화에서 완료한 사이트 작업과 모델 후보·요금 조사까지.

## 1. 현재 결론

사이트에는 3종의 모델 호출 코드와 첫 화면 입력 흐름을 반영했습니다. 추가 2종은 후보로 추천하고 비용을 조사한 단계입니다. API 키는 미등록 상태이며, 실제 모델 호출은 실행하지 않았습니다.

이번 요청에서는 여기까지의 내용을 문서로 정리하고, 추가 모델 적용·결제·충전·호출은 진행하지 않습니다.

사이트: https://project-times-workbench-kiwoo.kiwoo-02.chatgpt.site/
최근 확인한 공개 버전: 5

## 2. 모델 5종 구성안과 적용 상태

| 슬롯 | 모델 | API 제공자 | 현재 상태 |
|---|---|---|---|
| A | DeepSeek Flash | DeepSeek | 서버 호출 코드·화면 반영, API 키 미등록 |
| B | Qwen3.5-Plus | Alibaba Cloud Model Studio | 서버 호출 코드·화면 반영, API 키·지역 주소 등록 필요 |
| C | Gemini 3.8 Flash | Google Gemini API | 서버 호출 코드·화면 반영, API 키 미등록 |
| D | GPT-OSS 120B | Groq | 추가 후보 추천만 완료, 사이트에는 미지정으로 남음 |
| E | Mistral Small 4 | Mistral AI | 추가 후보 추천만 완료, 사이트에는 미지정으로 남음 |

세 모델과 추가 후보 두 모델은 수학 문제의 풀이·논리 추론을 비교하기 위한 구성입니다. 동일한 문제·조건으로 5종의 수학 성능을 실측한 결과는 없습니다. 이 구성이 정확도 최상위임을 검증했다는 뜻은 아닙니다.

이 모델들은 일반 추론 모델이며 Lean 같은 형식 증명기나 SymPy 계산 엔진과 동일하지 않습니다. SymPy·Lean의 실제 실행 연결은 아직 없습니다.

## 3. GPT-OSS와 Mistral Small의 의미

GPT-OSS는 ChatGPT 안의 세부 기능이 아니라 OpenAI가 가중치를 공개한 별도 모델 계열입니다. 이번 추천 방식은 사이트 → Groq API → GPT-OSS 120B입니다. OpenAI가 모델을 개발했고 Groq가 API 실행을 제공하는 구성이며, ChatGPT Plus 구독과 별개입니다.

Mistral Small 4는 프랑스 Mistral AI의 모델입니다. 수학·논리 추론을 지원하는 후보로 추천했으며, 공식 API 사용에는 결제 활성화와 사용량 과금이 필요합니다. 무료 채팅·Studio 이용과 무료 API 이용은 구분해야 합니다.

## 4. 첫 화면과 평가 흐름

1. 사이트 첫 화면의 ‘검색어 / 질문’에 입력합니다.
2. A~E 카드에서 모델과 전달할 prompt 파라미터의 미리보기를 확인합니다.
3. ‘평가’ 버튼을 누르면 기존 분석 화면으로 이동합니다.
4. 입력한 질문과 모델별 전달·응답 상태를 표시합니다.
5. ‘질문 수정’으로 돌아오면 현재 페이지의 입력 내용이 유지됩니다.

현재 A~C는 API 키가 없어 선택 체크박스가 비활성화되어 있습니다. D·E는 모델 미지정입니다. 이 상태에서 평가 화면을 열면 외부에 검색어를 보내지 않고 ‘미실행’ 사유를 표시합니다.

실제 요청에는 API 키 등록, 소유자 로그인, 실행 모델 선택, 과금 가능성 확인이 필요합니다. 사이트 열람은 공개이지만 소유자의 키를 사용하는 모델 실행은 소유자에게만 허용됩니다.

입력한 검색어는 모델에 보내는 질문 파라미터입니다. 이 입력만으로 별도 웹 검색 엔진이 실행되는 것은 아닙니다.

## 5. API 단가

아래는 2026년 11월 11일 대화에서 공식 문서로 확인한 텍스트 표준 호출 요금입니다. 단위는 미국 달러 / 100만 토큰이며, 무료 한도·캐시 할인·배치 할인은 적용하지 않았습니다.

| 모델 | 입력 100만 토큰 | 출력 100만 토큰 | 기준 |
|---|---:|---:|---|
| DeepSeek Flash | $0.15~0.30 | $0.60~1.20 | 비혼잡/혼잡 시간, 캐시 미적중 |
| Qwen3.5-Plus | $0.40 | $2.40 | 싱가포르 International, 입력 256k 이하 |
| Gemini 3.8 Flash | $0.75 | $3.75 | 2026년 12월 31일까지의 할인 요금 |
| GPT-OSS 120B · Groq | $0.15 | $0.60 | 유료 표준 요금 |
| Mistral Small 4 | $0.15 | $0.60 | 유료 표준 요금 |
| 단가 합계 | $1.60~1.75 | $7.95~8.55 | 각 모델에 같은 토큰 수를 사용한 경우 |

토큰은 글자 수와 같지 않습니다. 한국어, 수식, 시스템 지시문, 응답 길이에 따라 실제 토큰 수가 달라집니다.

DeepSeek의 가격 범위는 시간대에 따른 차이입니다. Gemini는 공식 안내상 2027년 1월 1일부터 입력 $1.50 / 출력 $7.50로 변경될 예정입니다. 다른 단가가 같다는 가정에서 아래 1,000회 예시는 그때 $16.40~17.30이 됩니다.

## 6. 다섯 모델 합산 비용 예시

가정:

- 평가 1회 = 같은 질문을 모델 5종에 각각 1번씩 요청.
- 모델마다 입력 2,000토큰, 과금 대상 출력 1,000토큰 사용.
- 입력에는 시스템 지시문 등 전송되는 전체 입력이 포함된 것으로 가정.
- 무료 한도·캐시 할인·추가 도구·재호출·세금·환율 수수료는 제외.
- 출력 1,000토큰을 넘는 과금 대상 추론 토큰이 발생하면 추가 비용이 생김.

계산식:

`평가 비용 = Σ[(각 모델 입력 토큰 × 입력 단가 + 각 모델 출력 토큰 × 출력 단가) ÷ 1,000,000]`

| 모델 | 평가 1,000회에서 해당 모델의 비용 |
|---|---:|
| DeepSeek Flash | $0.90~1.80 |
| Qwen3.5-Plus | $3.20 |
| Gemini 3.8 Flash | $5.25 |
| GPT-OSS 120B · Groq | $0.90 |
| Mistral Small 4 | $0.90 |
| 합계 | $11.15~12.05 |

| 다섯 모델 평가 횟수 | 총 모델 호출 수 | 합산 예상 비용 |
|---|---:|---:|
| 1회 | 5회 | $0.01115~0.01205 |
| 100회 | 500회 | $1.115~1.205 |
| 1,000회 | 5,000회 | $11.15~12.05 |

월 정액이 아니라 사용량 예시입니다. 예를 들어 한 달에 위 조건으로 1,000회 평가하면 해당 범위가 월 예상 모델 사용료가 됩니다. 초기 충전 최소금액, 미사용 잔액, 사이트 운영비 등은 이 표에 포함하지 않았습니다.

## 7. 무료 사용과 비용 관리

Groq는 GPT-OSS 120B의 무료 API 한도를 안내합니다. 확인 당시 기본 무료 한도는 분당 30회, 하루 1,000회, 분당 8,000토큰, 하루 200,000토큰이며, 계정의 실제 한도가 우선합니다. 요청 수와 토큰 한도를 모두 충족해야 하므로 하루 1,000개의 긴 문제를 무료로 처리할 수 있다는 뜻은 아닙니다.

Gemini 3.8 Flash도 공식 요금표에 무료 등급이 있지만 계정·모델 접근과 한도 조건을 확인해야 합니다. 무료 한도 적용 시 합산 비용은 낮아질 수 있습니다. Mistral의 Free 모드는 공식 안내상 API 접근을 포함하지 않습니다.

예산이 부족한 경우에는 무료 한도로 가능한 모델부터 소규모로 시험하고, 유료 모델을 항상 동시에 실행하지 않는 구성이 적합하다는 제안을 드렸습니다. 이번 문서 작성 중에는 가입·결제·충전·실제 API 호출을 하지 않았습니다.

## 8. 검증과 해석의 범위

- 이전 구현에서 보안·모의 연동·기존 합산 테스트 11건이 통과했습니다.
- 테스트에는 모의 공급자 응답을 사용했으며 실제 공급자 API 연결 성공을 검증한 것은 아닙니다.
- 첫 화면 검색어 반영 → 모델별 prompt 미리보기 → 평가 버튼 → 분석 화면 전환을 브라우저에서 확인했습니다.
- 공개 사이트 반영을 확인했습니다. 문서 작성 시 사이트를 추가 수정하거나 재배포하지 않았습니다.
- 기존 차트와 후보 A~E의 점수는 합성 예시입니다. 위 모델 슬롯 A~E의 실측 성능과 연결되지 않습니다.
- 실제 풀이에 자동 신뢰점수를 부여하지 않습니다. 모델 답변의 일치·다수결은 수학적 증명이나 사실 확정이 아닙니다.
