# Modules
Add independent feature folders here. Each feature can have its own backend/frontend/tests if needed.

## evaluation-workbench

검색어 입력 → 모델별 파라미터 → 평가 → 결과 화면의 독립 기능입니다. [모듈 설명](evaluation-workbench/README.md)과 [저장소 실행 흐름](../docs/WORKFLOW.md)을 확인하세요.

## 세부 코드 문서

평가 작업대의 [화면](evaluation-workbench/public/README.md), [서버](evaluation-workbench/worker/README.md), [빌드](evaluation-workbench/scripts/README.md), [테스트](evaluation-workbench/tests/README.md)를 각각 설명합니다. [전체 코드 지도](../docs/CODE_GUIDE.md)에서 기존 앱 문서도 확인할 수 있습니다.
