# Project Times

공개 수학 풀이 비교 작업대. DeepSeek Flash, Qwen3.5-Plus, Gemini 3.8 Flash를 서버 경유로 호출하는 어댑터를 제공합니다. API 키가 없으면 외부 호출을 차단합니다. 합성 예시 점수와 실제 모델 응답은 분리하며, 실제 풀이에는 자동 신뢰점수를 부여하지 않습니다.

## 실행

저장소 루트에서 `node scripts/workbench.mjs check`로 검증하고 `node scripts/workbench.mjs start`로 실행합니다. 브라우저에서 http://127.0.0.1:5173/ 을 엽니다. 모듈 폴더에서 `npm run build`, `npm test`, `npm run dev`를 사용할 수도 있습니다. 런타임은 Cloudflare Worker이며 공개 자산은 빌드 시 Worker에 포함됩니다. `public/`이 화면 원본, `worker/index.mjs`가 서버 원본입니다.

## 서버 비밀 설정

Sites 환경변수에 MODEL_OWNER_EMAIL, DEEPSEEK_API_KEY, QWEN_API_KEY, QWEN_BASE_URL, GEMINI_API_KEY를 등록하고 다시 배포합니다. QWEN_BASE_URL은 공식 계정 워크스페이스의 HTTPS `/compatible-mode/v1` 주소를 사용합니다. 키를 소스·브라우저·일반 로그에 저장하지 않습니다. 키 발급·충전·결제는 자동 수행하지 않습니다.

모델 실행은 Sites가 검증해 전달하는 로그인 ID·이메일을 확인해 소유자에게만 허용합니다. 클라이언트가 보낸 임의 신원 헤더를 신뢰하는 별도 프록시에는 배포하지 마세요. 공개 열람은 유지됩니다.

## 호출과 비용

각 실행에서 선택 모델에 최대 1회 요청하며 자동 재시도하지 않습니다. 문제 2,000자, 출력 max_tokens 1,024, Qwen thinking_budget 256, 대기 45초를 요청합니다. 무료 사용 여부·추론 토큰 계산·최종 청구는 공급자 정책에 따릅니다. 하드 지출 상한이 아니며, 대기 중단이 공급자 과금 취소를 보장하지 않습니다. 공급자 대시보드에서 별도 예산·사용량 제한을 설정하세요.

## 검증 범위

11건 로컬 테스트: 소유자 인증, CSRF, 비용 확인, 키 미등록, 모델·호스트 허용목록, 세 어댑터의 모의 응답, SSE 본문·사용량 처리, 오류 격리·비밀정보 제거, 정적 자산 제한, 기존 Q6 계산. 실제 공급자 키가 없어 실호출은 미실행입니다. SymPy·Lean 실행도 미연결입니다. 모델 풀이가 일치해도 수학적 증명이 아닙니다.

## 첫 화면 흐름

루트와 `#home`은 검색어 입력 화면입니다. A~C는 선정한 세 공급자, D·E는 미지정 슬롯으로 표시합니다. 입력 즉시 동일 prompt의 모델별 미리보기를 갱신하며, 평가 버튼 후 `#comparison`으로 이동해 입력 질문·전달 상태·실제 수신한 본문을 표시합니다. 키·로그인이 없으면 전송하지 않고 미실행 사유를 표시합니다. 합성 분석 차트는 별도 예시로 유지합니다. 질문 수정으로 돌아가도 입력은 현재 페이지 메모리에서 유지되며, 새로고침 시 실행 결과를 저장·복원하지 않습니다.

## 기존 실행 흐름과의 관계

이 폴더는 Sites 버전 5의 원본 소스를 기존 `modules/` 규칙에 따라 통합한 독립 작업대입니다. 루트 Docker/Spring/Python/DB 경로는 유지됩니다. Spring 로그인·DB와 이 Worker가 합쳐진 서비스는 아닙니다. 로컬 개발 서버는 127.0.0.1에만 바인딩하고 환경변수·신원 헤더를 Worker에 전달하지 않으므로 유료 호출은 비활성화됩니다. Sites의 플랫폼 인증 헤더를 일반 웹 서버의 사용자 입력 헤더로 대체하면 안 됩니다. 로컬에서 이를 우회하는 인증 URL은 없습니다.

A~C 호출 코드는 구현됐지만 실제 키 연결은 미검증이며 D·E는 미지정 상태입니다. GPT-OSS 120B와 Mistral Small 4는 추천 후보로만 문서에 기록했습니다. 비용 보고서는 [AI 5종 비용 정리](../../docs/research/Project_Times_AI_5_Model_Cost_Summary_2026-11-11.md)를 확인하세요. 이 코드를 커밋하는 것만으로 Sites가 다시 배포되지는 않습니다.
