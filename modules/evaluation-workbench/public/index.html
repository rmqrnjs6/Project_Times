METHODOLOGY / TRANSPARENT SCORING

계산은 투명하게, 해석은 신중하게.

첨부 작업 기록의 계산 설계를 기준으로 구성했습니다.

7개 지표와 초기 가중치

전문가 제외 · Q6

(.25F + .20S + .10I + .10T + .10C + .10(100−R)) ÷ .85

전문가 포함 · Q7

.25F + .20S + .10I + .10T + .10C + .10(100−R) + .15E

전후 향상은 같은 평가 기준에서 비교해야 합니다. Q6와 Q7의 차이를 곧바로 성능 개선으로 해석할 수 없습니다.

평균과 변화

평균은 동일 후보 집합의 점수 합을 후보 수로 나눕니다. 60 → 75점은 +15점이며 상대 향상률은 +25%입니다. 기준 평균이 0이면 상대 향상률은 정의되지 않습니다.

이 사이트의 범위

문서에 포함된 합성 순위와 계산 기준을 브라우저에서 재구성했습니다. 원래 Java·Python·DB 서비스와 연결되어 있지 않습니다. 문서에 적힌 과거 테스트 실적은 이 사이트의 검증 결과로 사용하지 않습니다.

아래 자료는 평가 설계의 해석 원칙을 뒷받침합니다. 이 사이트의 점수·가중치나 성능을 인증한 자료가 아닙니다.

  1. European Commission JRC · Step 6: Weighting ↗가중치는 종합값과 순위에 영향을 주므로 그 선택을 투명하게 밝혀야 합니다.

현재 계산식과 수치는 첨부 작업 기록에서 가져왔으며, 해석과 한계는 위 자료를 참고해 이 사이트의 방식에 맞춰 정리했습니다.
